SiBaCa - Pengembaraan Membaca Bikini Bottom

VERSI ANIMASI ALAM
- Obor-obor di padang obor-obor berdenyut, bercahaya dan menggerakkan sesungut.
- Air terjun di kiri gerbang batu mempunyai aliran, percikan dan riak bergerak.
- Semua ciri terdahulu dikekalkan termasuk kaki dalam air, peta, checkpoint dan aktiviti.

CARA BUKA
1. Extract All fail ZIP.
2. Buka folder SiBaCa_Game.
3. Buka index.html menggunakan Google Chrome.
4. Pastikan folder assets kekal bersebelahan index.html.

Nota: Animasi ini merupakan lapisan 2D di atas lukisan peta sedia ada, bukannya penggantian peta dengan animasi penuh.
